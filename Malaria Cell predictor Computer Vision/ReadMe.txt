# Malaria Cell Predictor (Computer Vision)

## 📊 Project Overview
This project applies **computer vision techniques** with OpenCV to detect malaria-infected cells from microscopic images. By leveraging image preprocessing and machine learning, the model classifies whether a given cell is **infected** or **healthy**, supporting faster and more reliable malaria diagnosis.

## 🛠 Tools & Libraries
- Python 3.10
- OpenCV
- NumPy
- Scikit-learn / TensorFlow
- Matplotlib / Seaborn

## 🔎 Key Features
- Preprocessing of cell images (grayscale conversion, resizing, normalization).
- Feature extraction using OpenCV methods (contours, texture analysis).
- Training a classification model to distinguish infected vs. uninfected cells.
- Evaluation with accuracy, precision, recall, and confusion matrix metrics.
