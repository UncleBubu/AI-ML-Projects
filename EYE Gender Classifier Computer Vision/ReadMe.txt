# Eye Shape Gender Classification

## 📊 Project Overview
This project applies **computer vision techniques** to classify whether an eye shape belongs to a **man or a woman**. By leveraging image-based features and machine learning, the model demonstrates how subtle facial attributes can be analyzed to infer demographic characteristics.

## 🛠 Tools & Libraries
- Python 3.x
- OpenCV
- NumPy
- Scikit-learn / TensorFlow / PyTorch (depending on implementation)
- Matplotlib / Seaborn

## 🔎 Key Features
- Preprocessing of eye images (cropping, resizing, normalization).
- Feature extraction using computer vision methods.
- Training a classification model to distinguish male vs. female eye shapes.
- Evaluation with accuracy and confusion matrix metrics.
