# Explainable AI (XAI)

## 📊 Project Overview
This project explores **Explainable Artificial Intelligence (XAI)**, focusing on methods that make machine learning models more transparent and interpretable. The goal is to help users and stakeholders understand **why** a model makes certain predictions, improving trust, accountability, and usability in AI systems.

## 🛠 Tools & Libraries
- Python 3.10
- Scikit-learn
- SHAP (SHapley Additive Explanations)
- Matplotlib

## 🔎 Key Features
- Provides explanations for model predictions.
- Uses SHAP and LIME to visualize feature importance.
- Demonstrates how complex models (e.g., Random Forests, Neural Networks) can be made interpretable.
- Enhances transparency in AI decision-making.
